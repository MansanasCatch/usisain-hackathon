Each analysis runs through a 5-step sequential pipeline (Step 1 → 2 → 3 → 4 → 5). Steps execute one after the other — each subsequent step builds on the outputs of the previous ones. Every step has a configurable timeout set in .env via PIPELINE_STEP_TIMEOUT_SECONDS. If a step fails or times out, the error is logged and the pipeline continues.
